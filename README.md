# CPU-Scheduling-Simulator
A Python CPU scheduling simulator for the Operating Systems Lab PBL at IST. It implements FCFS, SJF, SRTF, Priority (preemptive and non-preemptive), Round Robin and a bonus MLFQ. It calculates waiting, turnaround and response times and CPU utilization, draws Gantt charts and compares all algorithms. Reads CSV input and runs in Google Colab.
